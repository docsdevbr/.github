# Contributing Guidelines

[![CONTRIBUTING file in English][contributing-badge-en]][contributing-en]
[![CONTRIBUTING file in Brazilian Portuguese][contributing-badge-pt-br]][contributing-pt-br]

Thank you for considering contributing to docs.dev.br! This document provides guidelines for contributing to our project.

## Ways to Contribute

1. Translating documentation
2. Reviewing translations
3. Fixing typos and grammar
4. Improving existing content
5. Adding new documentation

## Getting Started

1. Fork the repository
2. Create a new branch for your contribution
3. Make your changes
4. Submit a Pull Request

## Translation Guidelines

- Maintain technical terms in their original form when appropriate
- Keep the same formatting as the original content
- Include references to the original documentation
- Follow Brazilian Portuguese grammar and spelling rules

## Pull Request Process

1. Ensure your PR description clearly explains the changes
2. Link related issues if applicable
3. Update any relevant documentation
4. Wait for review from maintainers

## Questions?

Feel free to open an issue for questions or visit our website at [docs.dev.br](https://docs.dev.br).
