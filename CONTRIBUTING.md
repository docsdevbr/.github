# Contribuindo

[![Arquivo CONTRIBUTING em inglês][contributing-badge-en]][contributing-en]
[![Arquivo CONTRIBUTING em português brasileiro][contributing-badge-pt-br]][contributing-pt-br]

Obrigado por considerar contribuir para docs.dev.br! Este documento fornece diretrizes para contribuir com nosso projeto.

## Como contribuir

1. Traduzindo documentação
2. Revisando traduções
3. Corrigindo erros de digitação e gramática
4. Melhorando o conteúdo existente
5. Adicionando nova documentação

## Começando

1. Faça um _fork_ do repositório
2. Crie um novo _branch_ para sua contribuição
3. Faça suas alterações
4. Envie um _Pull Request_

## Diretrizes de tradução

- Mantenha os termos técnicos em sua forma original quando apropriado
- Mantenha a mesma formatação do conteúdo original
- Inclua referências à documentação original
- Siga as regras de gramática e ortografia do português do Brasil

## Processo de Pull Request

1. Garanta que a descrição da sua PR explique claramente as alterações
2. Vincule problemas relacionados, se aplicável
3. Atualize qualquer documentação relevante
4. Aguarde a revisão das pessoas mantenedoras

## Dúvidas?

Sinta-se à vontade para abrir uma _issue_ para perguntas ou visite nosso site em [docs.dev.br](https://docs.dev.br).
